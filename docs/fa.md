# معرفی فارسی

**woocommerce-mcp** یک سرور متن باز بر پایه Model Context Protocol است که به کلاینت ها و ابزارهای سازگار با MCP اجازه می دهد یک یا چند فروشگاه ووکامرس را از طریق REST API مدیریت کنند. با آن می توان کاتالوگ محصولات را مرور کرد، سفارش ها را پیگیری کرد، مرجوعی ثبت کرد، قیمت و موجودی را به صورت گروهی تغییر داد و گزارش فروش گرفت.

## ویژگی های اصلی

- **چند فروشگاه در یک سرور:** هر فروشگاه کلید و تنظیمات جداگانه خودش را دارد و در هر درخواست می توان فروشگاه را انتخاب کرد.
- **امن به صورت پیش فرض:** فروشگاه ها تا وقتی اجازه نوشتن داده نشود فقط خواندنی هستند. هر تغییر اول به صورت پیش نمایش برگردانده می شود و فقط بعد از تایید اعمال می شود.
- **گزارش تغییرات:** هر تلاش برای نوشتن با جزئیات کامل در یک فایل ثبت می شود.
- **مرجوعی و عملیات گروهی:** مرجوعی کامل یا جزئی، ویرایش تا 100 محصول در یک مرحله و تغییر درصدی یا ثابت قیمت ها.
- **تحلیل فروش:** فروش روزانه، هفتگی و ماهانه، میانگین ارزش سفارش، پرفروش ترین محصولات و گزارش کمبود موجودی.
- **آماده اجرای راه دور:** اتصال HTTP با توکن یا OAuth 2.0، همراه با Docker و بررسی سلامت سرویس.
- **قابل مشاهده:** پشتیبانی از OpenTelemetry برای ردیابی هر درخواست.

## شروع سریع

</div>

```bash
WOOCOMMERCE_URL=https://store.example.com \
WOOCOMMERCE_CONSUMER_KEY=ck_... \
WOOCOMMERCE_CONSUMER_SECRET=cs_... \
npx -y woocommerce-mcp
```

<div dir="rtl" markdown>

کلید REST API را از مسیر WooCommerce > Settings > Advanced > REST API بسازید. تا وقتی فروشگاه فقط خواندنی است کلید Read کافی است.
